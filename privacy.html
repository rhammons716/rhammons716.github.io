Privacy policy

Kernel · Last updated 2 November 2026

Who runs it

Kernel is a private app run by its owner for himself. It is not offered to the public. Contact: rhammons716@gmail.com.

What Google data it accesses, and why

  • Google Calendar. It reads events to plan the week. It creates, moves and deletes only events it created itself, which are marked in the event description.
  • Google Tasks. It reads tasks and adds tasks.
  • Gmail. It reads messages to find events, deadlines and replies to its weekly email. It may label or trash obvious junk and create drafts. It does not send mail on the owner's behalf, except messages to the owner himself: the weekly summary and alerts when something needs his attention.

Where data is stored

Data is stored on the owner's own computer. OAuth tokens are stored locally and are never shared.

How data is processed

Some text is processed by AI models that run locally on that computer. Some is processed by Anthropic's Claude service to plan the week; see Anthropic's privacy policy.

Sharing

Kernel does not sell data, does not show advertising, and does not share data with anyone else. Data is transferred only as needed for the features described above.

Kernel's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data stays until the owner deletes it. Access can be revoked at any time at https://myaccount.google.com/permissions.

Changes

If this policy changes, it will be updated on this page and the date above will change.
